## Performance Baseline And Ceilings

- Startup to first useful result baseline / ceiling: Exact backend, Ubuntu 22.04.5, 10 fresh and 10 retained samples from spawn to `/api/auth/status`; superseded baseline fresh p95 `86.73 ms`, retained p95 `27.56 ms`; candidate observed fresh p95 `37.41 ms`, retained p95 `16.53 ms`; alpha backend ceiling `50 ms` p95, passed. Owner reported acceptable exact-AppImage first-use behavior but declined retaining a numeric desktop timing; that omission is accepted and the backend result is not presented as desktop latency.
- Idle memory baseline / ceiling: Exact backend, Ubuntu 22.04.5, 10 one-second `/proc` samples after 5 seconds; superseded baseline `14,604 KiB`, candidate observed `15,056 KiB` with `0.00%` sampled CPU; alpha host-server ceiling `32 MiB`, passed. Desktop WebView RSS was not retained and is an accepted alpha limitation.
- Installed footprint baseline / ceiling: Apparent extracted candidate payloads were DEB `190.856 MiB`, server `150.907 MiB`, AppImage `433.783 MiB`, and Windows portable `148.095 MiB`; compressed release ceilings are AppImage `220 MiB`, DEB `180 MiB`, server `150 MiB`, browser ZIP `25 MiB`, NSIS `300 MiB`, and Windows portable ZIP `300 MiB`; exact artifacts passed all budget gates.
- Worker cost per representative invocation baseline / ceiling: Exact packaged Node worker, Ubuntu 22.04.5, 10 fresh credential-free model-list invocations; superseded baseline p95 `309.50 ms` and `82,792 KiB`, candidate observed p95 `447.52 ms` and `81,464 KiB`; alpha ceiling `750 ms` and `128 MiB`, passed.

Record machine, operating system, build artifact, sample count, measurement
