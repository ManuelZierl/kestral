# Kestral v0.1.0-alpha.1

This is Kestral's first public testing release. It is intended for developers,
technical testers, and contributors. It is not production-ready.

Kestral is a personal-first, open-source AI workspace and lean local host for
user-chosen apps. Chat is available on first run, while focused apps remain
ordinary userland packages using the same grants, Runs, artifacts, and
provenance path.

## Included

- Windows current-user NSIS installer and portable archive.
- Linux AppImage and `.deb` desktop packages.
- Ubuntu backend archive and static browser client for split deployment.
- Local provider configuration, Chat, app installation and lifecycle,
  capability grants, trusted approval chrome, Runs, artifacts, and provenance.
- Sandboxed custom app surfaces and explicitly enabled native app backends.
- Independently released compatibility evidence for the exact external app
  packages recorded in `PROMOTED-APPS.json`.

## Important limitations

- Every native artifact is unsigned. Windows SmartScreen, Linux package tools,
  or managed-device policy may warn or block execution.
- Native app backends and stdio tool servers are not OS-sandboxed. After the
  explicit unsafe-backend opt-in, they run with the backend account's direct
  filesystem and network authority.
- This release does not support macOS, MSI, multi-user hosting, private Git app
  sources, or automatic app-data downgrade.
- The browser client is a trusted owner console. Use split mode only through
  HTTPS, a VPN, or an encrypted private tunnel to a backend you control.
- Development data created before this release has no compatibility path. From
  this release onward, later supported versions must migrate valid released
  data or refuse visibly while preserving the original.

Read the complete [release scope and risk notice](https://github.com/ManuelZierl/kestral/blob/main/docs/alpha-release.md)
and [known alpha limitations](https://github.com/ManuelZierl/kestral/blob/main/docs/honest-gaps.md)
before installing Kestral.

## Verify downloads

Download files only from this repository's GitHub release. Verify the selected
file against `SHA256SUMS.txt`. `BUILD-PROVENANCE.txt` records the exact source
commit and GitHub Actions run, and `THIRD-PARTY-NOTICES.txt` accompanies every
distribution. These records provide traceability; they are not code signatures.

Kestral Pi and every promoted reference app are optional independent projects,
not bundled Kestral release artifacts. Verify their repositories, package
digests, and evidence through `PROMOTED-APPS.json`.

Report defects with the **Alpha bug report** issue template. Report suspected
security vulnerabilities through [private vulnerability reporting](https://github.com/ManuelZierl/kestral/security/advisories/new).
