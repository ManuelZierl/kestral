# Kestral host

Kestral is a personal-first, open-source AI workspace and lean local host for
user-chosen apps. Chat is the default starting app, not the canonical interface
for all AI work.

This directory contains the Tauri 2 shell, SvelteKit frontend, bundled provider
worker, and native host crate. `v0.1.0-alpha.1` is the planned first public
testing release and has not been published.

Use the repository [README](../README.md) and
[documentation](../docs/index.md) for supported setup and product behavior.

```sh
npm install
npm run check
npm test
npm run tauri dev
```
